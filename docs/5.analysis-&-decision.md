## 3. Module Structure
The important part is what each module is responsible for.
data
data/
├── generator.py
├── workloads.py
└── validator.py
generator.py
Creates the actual test data.
generate_flat_data()
generate_nested_data()
generate_text_heavy_data()
generate_numeric_data()
workloads.py
Defines experimental workload configurations.
For example:
## Small
## Medium
## Large

Low redundancy
Medium redundancy
High redundancy
validator.py
Makes sure the decoded data is identical to the original data.

This should be completely independent.

deserialize(payload)
